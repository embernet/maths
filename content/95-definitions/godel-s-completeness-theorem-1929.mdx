## Definition

**Gödel's completeness theorem (1929):** A sentence $\phi$ is a logical consequence of a set of axioms $\Sigma$ (i.e., true in every model of $\Sigma$) if and only if there is a formal proof of $\phi$ from $\Sigma$ using the inference rules of first-order logic.
