## Definition

A **metric space** is a set $X$ together with a function $d : X \times X \to [0, \infty)$ satisfying:
1. $d(x, y) = 0$ if and only if $x = y$.
2. $d(x, y) = d(y, x)$ (symmetry).
3. $d(x, z) \le d(x, y) + d(y, z)$ (triangle inequality).
