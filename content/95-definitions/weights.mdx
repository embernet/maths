## Definition

where each layer applies an **affine transformation** followed by a nonlinearity: $f_l(\mathbf{z}) = \sigma(W_l \mathbf{z} + \mathbf{b}_l)$. Here $W_l$ is a matrix of **weights**, $\mathbf{b}_l$ a vector of **biases**, and $\sigma$ a fixed nonlinear activation function (ReLU: $\sigma(t) = \max(0,t)$ is now standard).
