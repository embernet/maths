## Definition

The Cantor set is what remains. Its properties are striking:
- **Measure zero**: the total length removed is $\frac{1}{3} + \frac{2}{9} + \frac{4}{27} + \cdots = 1$, so $C$ has Lebesgue measure 0
- **Uncountable**: $C$ has the same cardinality as $[0,1]$ (via ternary expansions)
- **Perfect**: every point is a limit of other points in $C$; no isolated points
- **Nowhere dense**: $C$ contains no open interval
