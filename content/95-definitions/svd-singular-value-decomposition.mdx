## Definition

The **SVD (Singular Value Decomposition)**: every $m \times n$ matrix $A$ can be written as $A = U\Sigma V^T$ where $U, V$ are orthogonal and $\Sigma$ is diagonal with non-negative entries (singular values). SVD is used for low-rank approximation (recommender systems, image compression, PCA in statistics), and is numerically the most stable decomposition for ill-conditioned problems.
