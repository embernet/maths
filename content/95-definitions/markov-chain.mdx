## Definition

Model the web as a **directed graph**: nodes are pages, an edge from $i$ to $j$ exists if page $i$ has a link to page $j$. Define the **transition matrix** $P$ where $P_{ij} = 1/(\text{out-degree of } i)$ if there is a link $i \to j$, and $0$ otherwise. A random web-surfer following links at random defines a **Markov chain** with transition matrix $P$.
