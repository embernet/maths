## Definition

A **set** is a collection of distinct objects (its elements). The fundamental relation is membership: $x \in A$. Set operations include union ($A \cup B$), intersection ($A \cap B$), complement ($A^c$), and power set ($\mathcal{P}(A)$ — the set of all subsets of $A$).
