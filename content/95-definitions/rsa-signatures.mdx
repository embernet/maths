## Definition

**RSA signatures**: to sign message $m$, compute the hash $h = H(m)$ (where $H$ is a cryptographic hash function such as SHA-256) and compute $\sigma = h^d \bmod n$ using the private exponent $d$. To verify, check that $\sigma^e \equiv H(m) \pmod{n}$ using the public exponent $e$. The correctness follows from the same Euler's theorem argument as RSA encryption.
