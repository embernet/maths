## Definition

**Classic example:** $\sqrt{2}$ is irrational. Assume $\sqrt{2} = p/q$ in lowest terms. Then $2q^2 = p^2$, so $p^2$ is even, so $p$ is even, so $p = 2k$, so $4k^2 = 2q^2$, so $q^2 = 2k^2$, so $q$ is even — contradicting $p/q$ being in lowest terms.
