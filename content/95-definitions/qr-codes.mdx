## Definition

**QR codes** use a specific Reed-Solomon code over $\mathbb{F}_{256} = \mathbb{F}_{2^8}$ (a degree-8 field extension of $\mathbb{F}_2$, constructed via an irreducible polynomial). The high-redundancy levels allow up to 30% of a QR code to be obscured — which is why you can print a logo on top of a QR code and it still scans.
