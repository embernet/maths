## Definition

**Statistical baselines**: model normal behaviour by fitting a probability distribution to historical data. For numerical features (login frequency, bytes transferred, API call rates), a Gaussian model $X \sim N(\mu, \sigma^2)$ is common; $\mu$ and $\sigma^2$ are estimated from normal observations by maximum likelihood. For count data, a Poisson or negative-binomial model is typical.
