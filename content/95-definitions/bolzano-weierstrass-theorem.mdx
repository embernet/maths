## Definition

**Bolzano-Weierstrass Theorem.** Every bounded sequence has a convergent subsequence. This is proved using the supremum axiom. [Bolzano](/mathematicians/bolzano) established versions of this result decades before [Weierstrass](/mathematicians/weierstrass) made it a cornerstone of rigorous analysis.
