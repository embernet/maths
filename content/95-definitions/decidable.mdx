## Definition

Hilbert's programme, developed in the 1920s, sought to:
1. Formalise all of mathematics as a formal axiomatic system
2. Prove that this system is **consistent** (cannot derive contradictions) — using only finitary methods
3. Prove that the system is **complete** (every mathematical truth is provable)
4. Prove that the system is **decidable** (an algorithm exists to determine whether any statement is provable)
