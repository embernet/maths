## What it says

A **Turing machine** consists of:
- An infinite tape divided into cells, each containing a symbol from a finite alphabet
- A read/write head positioned over one cell
- A finite set of **states** $Q$, including a start state and halting states
- A **transition function** $\delta: Q \times \Gamma \to Q \times \Gamma \times \{L, R\}$ specifying, given the current state and symbol under the head, the new state, symbol to write, and direction to move

The machine halts when it reaches a halting state. A function $f: \mathbb{N} \to \mathbb{N}$ is **computable** if some Turing machine computes it.

The **Church–Turing thesis** (not a theorem, but a hypothesis) asserts that the class of functions computable by Turing machines coincides with every other reasonable model of computation — lambda calculus, recursive functions, modern computers.

A **universal Turing machine** can simulate any other Turing machine given its description as input — the first theoretical model of a programmable computer.

## History

[Turing](/mathematicians/turing) published "On Computable Numbers, with an Application to the Entscheidungsproblem" in 1936, aged 23, while a graduate student at Cambridge. The paper simultaneously solved Hilbert's decision problem (negatively: no algorithm decides all mathematical questions) and established the theory of computation. Alonzo Church independently reached the same conclusion using lambda calculus the same year. Turing's formulation proved more influential because its mechanical character made the argument intuitive.

## Why it matters

Turing machines define the boundary of what is computationally possible — they separate decidable problems from undecidable ones. The theory of computational complexity (P vs NP and related questions) is built on Turing machines with resource bounds. Every computer ever built is, in principle, a physical realisation of a Turing machine.

## Real-world applications

The theory of computation underlies [cryptography](/applications/rsa-public-key-cryptography) (complexity assumptions distinguish tractable from intractable problems) and the foundations of [artificial intelligence](/applications/machine-learning-deep-neural-networks) (computability theory defines the limits of what machine reasoning can achieve).
