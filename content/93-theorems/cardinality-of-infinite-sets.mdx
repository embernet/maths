## What it says

Two sets $A$ and $B$ have the same **cardinality** (written $|A| = |B|$) if there exists a bijection $f: A \to B$. A set is **countably infinite** if it has the same cardinality as $\mathbb{N}$; **uncountable** if it does not.

Key results:
- $|\mathbb{N}| = |\mathbb{Z}| = |\mathbb{Q}|$ (all countably infinite — you can list them)
- $|\mathbb{R}| > |\mathbb{N}|$ (reals are uncountable — [Cantor's diagonal argument](/theorems/cantor-s-diagonal-argument))
- $|\mathbb{R}| = |\mathcal{P}(\mathbb{N})|$ (the reals have the same cardinality as the power set of $\mathbb{N}$)
- $|A| < |\mathcal{P}(A)|$ for every set $A$ (Cantor's theorem) — so there is no largest cardinality

The infinite cardinalities are denoted $\aleph_0$ (countable), $\aleph_1$, $\aleph_2$, …

## History

[Cantor](/mathematicians/cantor) developed the theory of cardinality between 1874 and the early 1890s, in the face of considerable hostility from contemporaries including Kronecker. His definition — two sets have the same size if and only if there is a bijection between them — is now completely standard but was controversial: it seemed to say that the even numbers and the natural numbers are "the same size," contradicting the ancient principle that the whole is greater than any of its parts.

The **Continuum Hypothesis** — whether $|\mathbb{R}| = \aleph_1$ (i.e., whether there is any cardinality strictly between $|\mathbb{N}|$ and $|\mathbb{R}|$) — was shown to be undecidable from the standard axioms of set theory by Gödel (1938) and Cohen (1963).

## Why it matters

Cantor's cardinality theory is the foundation of modern set theory and mathematical logic. It established that there are multiple, genuinely distinct infinities, and that asking "how big is this infinite set?" is a precise mathematical question with precise answers. The independence of the Continuum Hypothesis showed that even very natural questions can be unanswerable from standard axioms.

## Real-world applications

No direct engineering applications — but the decidability/computability limits that flow from this work set hard constraints on what algorithms can compute.
