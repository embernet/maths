## What it says

A **set** is a collection of distinct objects (its elements). The fundamental relation is membership: $x \in A$. Set operations include union ($A \cup B$), intersection ($A \cap B$), complement ($A^c$), and power set ($\mathcal{P}(A)$ — the set of all subsets of $A$).

Cantor's key results: the power set of any set has strictly greater cardinality than the set itself ($|A| < |\mathcal{P}(A)|$); there is no universal set (a set of all sets leads to Russell's paradox); and infinite sets can be compared by cardinality, with $|\mathbb{N}| < |\mathbb{R}|$.

The modern axiomatic framework (ZFC — Zermelo–Fraenkel axioms with the Axiom of Choice) was developed to avoid the paradoxes that Cantor's naive set theory encountered.

## History

[Cantor](/mathematicians/cantor) developed set theory between 1874 and 1897, working at Halle in the face of hostility from Kronecker, who called set theory "a disease from which mathematics will eventually recover." Cantor suffered repeated mental breakdowns, partly attributed to the stress of the controversy. Frege, Russell, and Hilbert saw set theory as the foundation for all mathematics; Russell's paradox (1901) forced the move to axiomatic set theory.

## Why it matters

Set theory is the universal language of mathematics: every mathematical object — function, relation, number, space — can be defined as a set. The axiomatic treatment of set theory also made precise what "proof" means and what "consistency" requires, feeding directly into the mathematical logic of Gödel and Turing.

## Real-world applications

No direct engineering applications, but set-theoretic thinking pervades database theory, type systems in programming languages, and the foundations of computer science.
