## What we are proving

For any natural numbers $m$ and $n$:

$$m + n = n + m.$$

Addition of natural numbers is commutative. This feels obvious, but if you try to prove it from the recursive definition of `Nat.add` directly, you quickly discover that the asymmetry of the definition (recursion on the second argument) means you need two prior lemmas: `zero_add` (proved on the previous page) and `add_succ` (which says `m + (n + 1) = (m + n) + 1`). This is a compound induction.

```lean
theorem add_comm (m n : Nat) : m + n = n + m
```

## The proof

```lean
-- 06-add-comm.lean
import Mathlib.Tactic

namespace MathsCompanion

-- We need this auxiliary lemma first
theorem add_succ' (m n : Nat) : m + n.succ = (m + n).succ := rfl

theorem zero_add' (n : Nat) : 0 + n = n := by
  induction n with
  | zero      => rfl
  | succ k ih => simp [Nat.add_succ, ih]

-- Main theorem: addition is commutative
theorem add_comm' (m n : Nat) : m + n = n + m := by
  induction n with
  | zero =>
    simp [zero_add', Nat.add_zero]
  | succ k ih =>
    rw [Nat.add_succ, ih, Nat.succ_add]

end MathsCompanion
```

## Walk-through

We induct on `n`.

**Base case (`n = 0`):** We need `m + 0 = 0 + m`. The left-hand side reduces by `Nat.add_zero` to `m`. The right-hand side needs `zero_add'`, which gives `0 + m = m`. Both sides equal `m`, so `simp` closes it.

**Inductive step (`n = k + 1`):** We have inductive hypothesis `ih : m + k = k + m`. The goal is `m + (k + 1) = (k + 1) + m`.

- `rw [Nat.add_succ]` — rewrites `m + (k + 1)` to `(m + k) + 1`, using the definition of addition. Goal becomes `(m + k) + 1 = (k + 1) + m`.
- `rw [ih]` — substitutes `k + m` for `m + k`. Goal becomes `(k + m) + 1 = (k + 1) + m`.
- `rw [Nat.succ_add]` — uses `Nat.succ_add : (n + 1) + m = (n + m) + 1` (note: `k + 1 = k.succ`). This rewrites `(k + 1) + m` to `(k + m) + 1`. Both sides are now `(k + m) + 1`, so `rfl` closes it automatically.

The structure of the proof — building `add_comm` on top of `zero_add` and `add_succ` — is typical of how Lean proofs are layered. You rarely prove anything from first principles; you assemble prior lemmas.

In practice, Lean already has `Nat.add_comm` in its core library and Mathlib has `add_comm` for any `AddCommMonoid`. The point of reproving it here is to understand the architecture: how a seemingly obvious fact requires a chain of definitions and lemmas.

## Try it yourself

Prove `add_assoc : (m + n) + p = m + (n + p)` by induction on `p`. The structure is similar: base case by `rfl`, inductive step by rewriting with `add_succ` and the hypothesis. If you can prove commutativity and associativity, you have established that `(Nat, +, 0)` is a commutative monoid — exactly the `AddCommMonoid` typeclass in Mathlib.
