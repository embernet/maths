## The application

When data is transmitted over a noisy channel — a scratched CD, a cosmic-ray-hit memory chip, a satellite link across 20 billion kilometres — some bits will be corrupted. **Error-correcting codes** add structured redundancy so that the original data can be recovered even after a certain number of errors. The mathematical foundation is linear algebra over finite fields, with Galois theory providing the deepest results.

## The maths behind it

A **linear code** $\mathcal{C}$ is a subspace of $\mathbb{F}_q^n$ (the vector space of $n$-dimensional vectors over a finite field with $q$ elements). A **$(n, k)$ code** encodes $k$ information symbols into $n$ transmitted symbols; the $(n-k)$ redundant symbols allow error detection and correction.

The minimum **Hamming distance** $d$ of a code — the minimum number of positions in which any two codewords differ — determines its error-correction capability: the code can correct $\lfloor (d-1)/2 \rfloor$ errors. The **Singleton bound** and **Hamming bound** limit $d$ as a function of $n$ and $k$.

**Reed-Solomon codes** (1960) achieve the Singleton bound: they are the most efficient possible codes for their parameters. A Reed-Solomon code over $\mathbb{F}_{q}$ treats a message as a polynomial $m(x) = m_0 + m_1 x + \cdots + m_{k-1} x^{k-1}$ and encodes it as the vector of evaluations $(m(\alpha^0), m(\alpha^1), \ldots, m(\alpha^{n-1}))$, where $\alpha$ is a primitive root of $\mathbb{F}_q$. Error correction uses polynomial interpolation and the algebraic structure of $\mathbb{F}_q$ — specifically, the factorisation theory of polynomials over finite fields, which requires [Galois theory](/03-specialisation-year-three/01-galois-theory).

**QR codes** use a specific Reed-Solomon code over $\mathbb{F}_{256} = \mathbb{F}_{2^8}$ (a degree-8 field extension of $\mathbb{F}_2$, constructed via an irreducible polynomial). The high-redundancy levels allow up to 30% of a QR code to be obscured — which is why you can print a logo on top of a QR code and it still scans.

## A concrete example

Voyager 1, at roughly 23 billion kilometres from Earth, communicates at 160 bits per second with a signal so weak that noise dominates. NASA uses **Golay codes** and **convolutional codes** — algebraically structured codes with provable error-correction properties — to recover the original data. Without error-correcting codes, the images from the outer planets could not have been transmitted at all.

## History of the application

Richard Hamming at Bell Labs invented the first systematic error-correcting code in 1950, motivated by frustration at having his overnight computing jobs halted by parity errors. Shannon's 1948 information theory paper established that reliable communication was theoretically possible over noisy channels, and Hamming and Reed-Solomon demonstrated how. The algebraic approach to coding — using finite field structure — was developed through the 1950s–60s.
